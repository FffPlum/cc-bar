# 统一宿主接口 v1

该接口为未来共享前端提供宿主边界；当前原生界面和启动流程不创建 WebView。Windows 宿主尚未实现。`Sources/CCBar/Core/HostAPI` 为 macOS 适配，`packages/host-api` 为 TypeScript SDK。

请求为 `{version:1,id:string,method:string,params:object}`。响应同版本及 id，且恰有 `result` 或 `{error:{code,message}}`；错误不会返回底层异常、凭据或账号原文。状态事件为 `{version:1,event:"state.changed",revision:string,domains:[...]}`，domain 为 `usage`、`quota`、`settings`；事件是缓存失效提示，可能合并多个 domain，不保证逐次变更。订阅随桥接安装建立、卸载取消，后台聚合及原生界面变更也会触发。revision 只在本服务实例内递增，不跨进程持久化。

| 方法 | 参数 | 返回与行为 |
|---|---|---|
| `host.describe` | `{}` | `{platform:"macos",timeZone,capabilities}`，能力为可调用的方法名 |
| `usage.overview` | `{from,to,service?}` | `{totals,samples:[{date,totals}]}`；范围为半开区间，日期必须是宿主 `timeZone` 对应的本地日零点 ISO 8601（带时区），不接受日中时间。按当前设置的可见服务与可选 service 过滤，日桶直接使用统计概览模型。 |
| `quota.snapshot` | `{}` | `{services:[{service,snapshot,refresh}]}`，仅七个主额度服务，尚不包含导入或托管副账号。snapshot 可为 null；含 fetchedAt、planType、isUnlimited 与 limits（id、kind、displayName、usedPercent、resetsAt、windowSeconds、isActive）。refresh 含 inFlight、backoffUntil、lastAttemptAt、lastSuccessAt、failed、source；时间及 source 可为 null，不提供底层错误文本。 |
| `quota.refresh` | `{}` | 调用原有用户触发额度刷新链并返回同样结构；遵守既有 429 退避及失败保留快照策略。旧快照不代表本轮成功，应检查 refresh。 |
| `settings.get` / `settings.update` | `{}` / `{patch:{privacyMode?,useInstalledAppIcons?}}` | 返回完整 `{privacyMode,useInstalledAppIcons}`；patch 先整体校验，未知字段和非布尔值拒绝，无部分写入。此集合只是 v1 安全子集。 |
| `platform.pickDirectory` | `{}` | `{path}`，取消时 path 为 null。 |
| `platform.revealPath` | `{path}` | 路径须为已存在的绝对路径，系统文件管理器中选中，返回 `{}`。 |
| `platform.setLaunchAtLogin` | `{enabled:boolean}` | `{enabled,requiresApproval}`，返回系统实际注册状态及是否需用户批准。 |

`totals` 包含 inputTokens、outputTokens、cacheReadTokens、cacheCreationTokens、totalTokens、costUSD、requestCount、hasUnpricedUsage、costIncomplete；金额以十进制字符串表示，缺价和计量不完整标记保留。Token 总数含缓存读写。日期与价格沿用现有聚合结果，不另做计价。样本日期为 ISO 8601，按宿主日历分桶。首次扫描尚未完成时返回现有已聚合快照，不触发扫描。

WebKit 适配器需调用方显式指定可信 URL、安装和卸载；只接受可信主框架，HTTPS 限定同 scheme/host/port，本地文件限定准确文件 URL。通过 `ccbarHost` 的 `WKScriptMessageHandlerWithReply` 通信，事件调用 `window.__ccbarHostReceiveEvent`。每个 content controller 同时只能有一个该名称的桥接；第二个 transport 的 `install` 返回 false，拥有者在关闭窗口或替换桥接前必须调用 `uninstall()`；弱代理避免 WebKit 强持有桥接本身，但不能替代显式清理。不要在不可信页面或远程可注入内容上安装。接口不暴露 token、原始凭据或通用文件读写。

## 定向验证

在 Swift 6.4.2 / Xcode 27.2 环境执行 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --filter 'HostAPITests|StatsOverviewModelTests'`，15 项通过（HostAPITests 7 项、StatsOverviewModelTests 8 项）。覆盖共享 wire fixture、统计模型和缓存 token/费用/过滤、设置原子校验及持久化、平台动作的成功与失败映射、额度旧快照与退避状态映射、后台变更订阅、实际 WebKit 消息与事件、来源判断和卸载重装。额度刷新以注入替身隔离，未触发真实网络、读取真实凭据或扫描用户日志；WebKit 仅用于测试，未接入应用窗口。

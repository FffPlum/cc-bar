# 供应商与额度管理分离：实施与验证记录

## 验收范围

1. 主侧栏只列已添加的应用；额度管理替代授权中心；底部并排应用 / 设置。
2. 添加供应商是独立内容页，具有搜索、分类侧栏和供应商卡片；包含所有已识别及已保存 API Key。
3. 额度管理只展示账号登录授权；Key 不再参与余额面板、菜单栏或桌面悬浮窗的额度展示与自动余额查询。
4. 应用管理复用现有安装 / 配置检测，集中提供侧栏添加及统计开关。
5. 应用内容只显示当前应用的账号 / API Key 连接信息，无切换、编辑、删除等行内功能按钮。
6. 沿用 Swift Package 分层；使用 ub-mode 检查冗余与公共逻辑。

## 操作与原因

- 核对六张参考图及当前源代码，确认卡片布局、供应商目录与底部应用 / 设置的关系。
- 先添加旧 API Key 显示偏好不能参与额度的回归测试；运行得到预期失败，再修改显示资格规则。
- 建立 `apiKeyProviders` 目录视图，引用现有凭据 store；保留旧 ID 与配置引用，避免复制迁移导致丢失。
- 新增 `deepSeekQuotaAccounts`，所有账号额度展示复用同一个过滤入口；自动刷新以包含授权种类的 `isVisible` 判定。
- 根据现有凭据实现与技术文档，将 Moonshot、Command Code、OpenCode Go 的 API Key 放入供应商目录，停止其自动额度展示和查询。旧凭据、缓存和底层解析能力保留。
- 将侧栏选择与统计可见性分开持久化，新增应用管理页；去除应用页的统计开关。
- 将供应商合并逻辑移到 `CCBarConfiguration.ProviderConnection`，供 Xcode 与 Swift Package 共用；同一供应商多个模型不重复成卡。
- 抽取共用 `ProviderInfoCard`、`ApplicationIcon` 与统一 `APIKeyEditor`。移除旧 Moonshot 余额视图、Key 账号表单，以及不再可达的 Command Code / OpenCode Go 额度凭据表单。
- 保留原生配置核心，但本轮应用卡片不提供切换 / 编辑 / 删除操作；目录添加只保存 CCBar 配置。
- 删除旧菜单栏 Moonshot 余额参数与未使用的批量刷新入口，简化只负责新增 Key 的表单，修复无原生供应商但有登录账号时的卡片数量。
- 同步产品需求、技术实现、布局、术语与项目指南。

## 验证

- 首轮回归：旧 API Key 的 `isVisible` 测试先失败，再通过。
- 首轮定向测试：22 项通过（账号隔离、旧凭据引用、侧栏持久化、供应商合并及既有 DeepSeek / 凭据测试）。
- 最终 Xcode Debug 构建通过：`/tmp/ccbar-quota-management-reviewed-build.log`，包含 `BUILD SUCCEEDED`。
- 最终 Swift Package 定向测试 39 项通过：App 侧 23 项，配置核心 16 项，日志 `/tmp/ccbar-quota-management-reviewed-tests.log`。覆盖旧显示偏好不能启用 API Key 额度、旧 Key 可被应用配置继续引用、侧栏选择持久化且不改变已发现应用、跨应用隔离与多模型卡片去重，以及既有配置读写 / 凭据 / DeepSeek 请求和回调。
- `git diff --check` 和 Xcode 工程 plist 检查通过。
- 实际 Debug 界面确认：侧栏没有「应用」分组标题；底部应用 / 设置并排；Codex 仅显示登录卡；Kimi 仅显示登录卡和 DeepSeek Key 卡，均没有行内切换 / 编辑按钮。
- 实际供应商目录确认：分类及计数正确，已识别 DeepSeek Key 标注来源 Kimi Code；点击后预填名称、地址、协议，不显示明文 Key。退出表单未保存测试配置。
- 实际应用管理确认：已识别的四个本机应用均列出，侧栏与统计两个开关分开；本轮界面验收未更改用户的统计或显示偏好。
- 实际额度管理确认：DeepSeek 只显示 DSH 登录授权及一份余额；不再显示 Kimi 配置中的 API Key 余额。登录新增 / 重新授权流程保留，未为了界面验收新增真实登录。
- 本轮未提交、发布或替换 `/Applications/CCBar.app`。

## ub-mode 检查

一处定义额度资格，账号与 Key 在视图模型中分流；界面不接收明文密钥。公共卡片与配置合并逻辑复用，未添加路由或聚合。当前环境未提供 crapper / dryer / mutator 工具，不能报告这些工具的评分；以代码审阅、行为测试和实际界面核对替代。

## 本版亮点

- 主窗口重新组织应用、额度和统计入口，可集中管理 18 款 CLI 与桌面应用
- 用量统计支持每周与历史累计视图，可切换柱状图和曲线面积图
- 登录账号与 API Key 分开管理，新增 DeepSeek Harness 账号余额

## 新增

- 「应用」按已安装和未安装分组，支持检查版本、安装、升级及指定安装位置卸载；卸载保留配置和历史记录
- 「额度管理 → DeepSeek Harness」支持浏览器授权和读取本机 DSH 登录，可查看充值与赠金余额

## 改进

- 「用量统计 → 用量设置 → 显示」可切换图表类型；面积图分别展示各应用趋势，悬停时标出对应采样点，缓存命中率按应用独立显示并共用最低应用的纵轴范围
- 「用量设置」新增自动扫描会话日志开关、扫描周期与「立刻同步」；自动扫描默认开启，关闭后仍可手动同步
- 「额度管理」集中展示官方登录账号，ChatGPT 导入仅接受 OAuth 凭据；API Key 改在应用的「添加供应商」目录管理，已有凭据保留，Moonshot API 余额及 Command Code、OpenCode Go 额度不再展示
- 账号的「菜单栏」与「悬浮窗」选择共同控制自动额度刷新；两项都取消后停止自动刷新，保留凭据和历史，应用用量统计单独设置

## 修复

- Codex：补计上下文压缩产生的 Token、请求数和费用；升级后自动补齐仍有日志的历史，保留已删除日志的已有统计
- 修复全屏或菜单栏自动隐藏时，展开额度面板后菜单栏提前收起的问题；刷新和查看状态时保持面板展开

## 本版亮点

- 在设置中查看模型价格目录，并选择费用显示货币
- 统计页用量构成支持在各维度悬停时突出对应占比

## 新增

- 「设置 → 数据与刷新」新增「价格目录」，可按提供商或模型搜索 models.dev 价格，并打开数据来源
- 「设置 → 数据与刷新 → 货币单位」支持美元、人民币等八种货币，费用和 Moonshot API 余额可按所选货币显示；默认使用美元

## 改进

- 「更新价格并重算用量」合并价格更新与历史重算，分别显示价格更新和重算结果；历史校验恢复后提示再次重算
- 菜单栏弹出面板底部新增版本与发布页入口，设置入口移至底部；官方状态详情可直接打开状态页
- 统计页悬停用量构成的列表项时，同步突出对应色块和占比条，支持减少动态效果

## 修复

- 修复价格目录无法显示已有价格，或后台加载完成后页面不刷新的问题
- 修复搜索价格目录后无法收起提供商列表的问题

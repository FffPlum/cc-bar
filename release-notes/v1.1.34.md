## 本版亮点

- 首次启动时更清楚地区分已登录、已安装和未发现的服务
- 查看多个账号的额度时，更容易辨认账号所属的服务
- 减少 CCBar 管理的账号在启动时重复请求钥匙串授权

## 改进

- 首次启动：各账号信息并行加载，加载中会显示进度提示；菜单栏选项只显示已发现并登录的服务
- 首次启动：未登录或未发现的服务使用灰色状态标识，列表下方的滚动提示更醒目并在几次引导后停止
- 额度面板：每个服务统一显示名称，账号昵称、邮箱和套餐排列在服务下方，多个账号之间增加分隔
- 账号授权：CCBar 管理的订阅凭据和手动 API Key 改为保存在仅当前用户可访问的本机文件中，旧账号首次迁移可能需要一次钥匙串授权；同一用户的其他进程仍可能读取这些文件
- Claude 桌面版和 Cursor：成功授权后的解密密钥保存在本机私有文件中，减少后续启动时的重复授权

## 修复

- 首次启动：修复已安装 Claude Code 但尚未登录时显示为未发现的问题
- 首次启动：修复已登录服务未出现在菜单栏选项中的问题

最近一个月新增的功能，你可能还没用过：

- 额度快用完时发系统通知，在「设置 → 通用 → 额度提醒」开启
- 统计页新增「项目」，按项目查看用量、费用、分支和对话
- 在「检查更新…」里查看更新内容，下载后自动安装并重启
- 在「设置 → 数据与刷新 → 网络代理」配置 CCBar 独立代理
- 在「设置 → 外观与显示 → 统计」切换 Tokens 或费用排行
- 在「设置 → 服务与账号」拖动服务，调整菜单栏和统计页顺序
- 统计页支持 Antigravity 的用量、对话和项目
- 在「设置 → 服务与账号」开启 OpenCode Go 额度
- 在概览「用量构成 → 模型」比较首字延迟和输出速度
